# 📚 Timetable B

A simple mobile-friendly timetable app for **B.Tech CSE — Section B**.

## ✨ Features

- 📅 Automatically opens on **today's timetable**
- 👆 Tap **Mon–Sat** to view another day
- ⏰ Shows class timings
- 📖 Shows subject and course code
- 📍 Shows the room/lab for each entry
- 📱 Designed for Android Chrome and home-screen installation
- 🔄 The selected day is recalculated automatically when the app is opened

## 📱 Install on Android

1. Open the GitHub Pages site in **Chrome**.
2. Open the Chrome menu **⋮**.
3. Select **Add to Home screen** or **Install app**.
4. Add **Timetable B** to your home screen.
5. Open it anytime to see the current day's timetable.
