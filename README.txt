SECTION B TIMETABLE — Chrome/PWA app

Files:
- index.html
- manifest.json
- sw.js

PHONE SETUP:
1. Put these files on a simple HTTPS website. GitHub Pages is a free option.
2. Open the website in Chrome on Android.
3. Chrome menu (⋮) -> Add to Home screen / Install app.
4. The home-screen icon opens the timetable in an app-like window.
5. It automatically selects the current day. Tap Mon-Sat to view another day.

The timetable data is transcribed from page 2 of the uploaded 3rd Semester Time Table 2026-27 PDF, Section B.
